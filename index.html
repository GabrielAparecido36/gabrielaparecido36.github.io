✂ Bot de Cortes

Ferramenta pessoal para transformar vídeos em cortes curtos e publicá-los no YouTube.

O que ele faz

O Bot de Cortes roda no computador do próprio dono. Ele corta vídeos em trechos curtos, gera legendas e, com a autorização do dono do canal, envia os cortes aprovados para o canal dele no YouTube usando a API oficial do YouTube.

Não é um serviço aberto ao público: só é usado pelo próprio dono, nos próprios canais.

▶ Usa os Serviços de API do YouTube

O Bot de Cortes usa os Serviços de API do YouTube (YouTube Data API v3). Ao usá-lo, você concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.
