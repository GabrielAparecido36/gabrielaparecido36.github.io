Política de Privacidade — Bot de Cortes

Última atualização: 13 de outubro de 2026

O Bot de Cortes é uma ferramenta pessoal que roda no computador do seu dono. Esta política explica como ele usa os dados do YouTube quando o dono do canal autoriza o acesso.

Uso dos Serviços de API do YouTube

O Bot de Cortes usa os Serviços de API do YouTube (YouTube Data API v3). Ao usar o Bot de Cortes, você concorda com os Termos de Serviço do YouTube. O uso dos dados também segue a Política de Privacidade do Google.

Quais dados são acessados

Com a autorização do dono do canal (login do Google / OAuth), o bot acessa apenas os dados dos próprios canais do dono: nome, identificador, foto e estatísticas públicas do canal (inscritos, visualizações, curtidas e comentários dos vídeos), a lista de vídeos e playlists do canal, e as permissões para enviar vídeos, editar título e descrição dos próprios vídeos, curtir os próprios vídeos e publicar um comentário neles. Para encontrar vídeos com licença Creative Commons, o bot faz buscas públicas na API (título, canal e licença de vídeos públicos).

Como os dados são usados

Somente para: publicar os cortes nos canais do dono (com crédito ao vídeo e ao canal de origem), mostrar no próprio bot o que já foi publicado e como cada vídeo está indo, e escolher melhores assuntos com base nas estatísticas dos próprios canais. Nenhum dado de outras pessoas é coletado.

Onde ficam guardados

A autorização do Google, o registro dos vídeos enviados e as estatísticas ficam guardados apenas no computador onde o bot roda. Não existem servidores do Bot de Cortes: a comunicação é direta entre esse computador e o Google/YouTube. Não usamos cookies nem rastreadores.

Compartilhamento

Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Exclusão dos dados

Ao desconectar um canal no bot, a autorização e as estatísticas guardadas daquele canal são apagadas na hora. As estatísticas dos canais conectados são atualizadas a cada leitura (nunca ficam mais de 30 dias sem atualizar). Se o acesso for revogado pela Conta Google, o bot mostra o canal como desconectado e, ao removê-lo, os dados são apagados. Para pedir a exclusão de qualquer dado, escreva para o contato abaixo (atendido em até 7 dias).

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google: security.google.com/settings/security/permissions. Depois de revogado, a autorização guardada deixa de funcionar.
